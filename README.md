## [COMPILING INSTRUCTIONS]
Since this is a legacy version, there are a lot of problems if these rules are not followed:
1. Install Haxe `4.2.4` (checkable via `haxe --version`)
2. Make sure Haxelib is version `4.0.2` (checkable via `haxelib version`)
3. Setup haxelib by doing `haxelib setup`
4. Install `hmm` (via `haxelib install hmm 3.1.0`)
5. Setup hmm by doing `haxelib --global install hmm` then `haxelib --global run hmm setup`
6. Go to the root directory of the source code and run `hmm install`
7. Afterward, do `haxelib run lime setup`
8. Compile the game by doing either `lime test windows` or `lime test windows -debug` (for debug builds)
